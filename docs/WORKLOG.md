# Журнал работ: LumiTales и StoryCharacters

Ветка: `claude/youthful-ride-j0wadw`. Дата: 7 октября 2026.

## Задача

Для каждого из пяти референсов создать идеального персонажа для iOS-приложения, которое генерирует и рассказывает сказки.
У каждого персонажа две версии: на Metal и без Metal.
Персонажи полностью анимированы, показывают разные эмоции и по-настоящему говорят, а не просто открывают рот.
Требования: максимальная милота, плавность и высокая производительность. Разрешено поднять минимальную версию до iOS 26 и переписать проект с нуля.

## Что удалено

Старый проект WeatherTest удалён целиком: CocoaPods, CoreData, погодные модули и workspace.

## Анимация

- **14 эмоций.** Спокойствие, радость, восторг, смех, удивление, любопытство, задумчивость, грусть, испуг, сонливость, ворчливость, смущение, влюблённость, внимание.
- **Каждая эмоция меняет всё лицо и тело.** Меняются веки, нижние веки, зрачки, брови, рот, наклон головы, румянец, свечение, поза и эффекты: слёзы, пот, сердечки, «Zzz», «?» и «!».
- **14 жестов.** Кивок, «нет-нет», прыжок, помахать, подумать, «ой!», смутиться, «ура!», подмигнуть, зевнуть, подглядеть, хихикнуть, уснуть, проснуться.
- **Плавность.** Все переходы идут через пружины второго порядка с подшагами, поэтому смена эмоции посреди движения не даёт рывков.
- **Жизнь в покое.** Есть случайное моргание с двойными морганиями, саккады взгляда, дыхание, парение, покачивание, мерцание пламени и микровыражения.
- **Реакция на касание.** Тап вызывает реакцию по характеру персонажа, а перетаскивание заставляет его следить взглядом за пальцем.
- **Доступность.** Учитывается системная настройка «Уменьшение движения».

## Речь

- **15 висем.** Каждая задаёт челюсть, ширину губ, округление, верхние и нижние зубы, язык и смыкание губ.
- **Висемы из текста.** Правила для русского и английского учитывают диграфы, мягкий и твёрдый знак, удвоенные буквы и паузы на знаках препинания.
- **Коартикуляция.** Соседние висемы перекрываются, гласные доминируют над согласными, кадр к кадру нет скачков.
- **Говорящая голова.** На начало каждого слова приходится кивок, брови подчёркивают ударение, улыбка эмоции сохраняется во время речи.
- **Три источника речи.** Встроенный синтез речи iOS с колбэками по словам. Внешнее аудио по громкости и тембру, подходит для серверного TTS. Готовые тайминги слов от сервера.

## Рендеринг

- **Metal.** Персонаж рисуется одним полноэкранным треугольником с SDF-шейдером, искры рисуются одним инстансным вызовом. Uniforms передаются через setFragmentBytes без аллокаций на кадр. Если скомпилированная библиотека шейдеров не найдена, шейдер компилируется из встроенной строки.
- **SwiftUI Canvas.** Тот же внешний вид без Metal, на TimelineView и Canvas. Есть два уровня качества свечения.
- **Фасад CharacterView.** Он сам выбирает Metal, если тот доступен.
- **Общая геометрия.** Оба рендерера реализуют одни и те же формулы глаз, бровей, рта, щёк, силуэтов и эффектов из контракта.

## Сказки

- **Разметка.** Парсер понимает теги эмоций, жестов, пауз и разрывов прямо в тексте.
- **Встроенные сказки.** Три русские: «Звёздная библиотека», «Колыбельная для Луны», «Самое терпеливое семечко». Две английские: «The Jar Full of Fireflies», «Puff and the Softest Pillow».
- **Генератор без сети.** Он собирает сказку из шаблонов по имени героя, месту, теме и языку. За протоколом StoryGenerating можно подключить LLM.
- **Плеер.** Ведёт персонажа по сегментам: ставит эмоцию, играет жест, озвучивает текст и подсвечивает текущее слово.

## Приложение

- **Вкладка «Персонажи».** Карусель из 8 персонажей, большая сцена, переключатель рендерера, сетка эмоций, панель жестов, поле для фразы с примерами на двух языках, счётчик кадров.
- **Вкладка «Сказки».** Список сказок, форма генерации и плеер с караоке-подсветкой слов.
- **Оформление.** Ночное небо с мерцающими звёздами под цвет персонажа и стиль Liquid Glass из iOS 26.
- **Фон.** Рендеринг ставится на паузу при уходе приложения в фон.

## Как шла работа

1. Написан контракт: общие типы и подробный документ с геометрией, API модулей, дизайн-библией и таблицей эмоций.
2. Семь модулей реализованы параллельно отдельными агентами строго по контракту.
3. Первый раунд ревью шёл через линзы компилятора, MSL, поведения, интеграции и арт-дирекции. Найдено 175 замечаний, из них 52 серьёзных. Верификатор подтвердил 45 серьёзных, все исправлены вместе с применимыми мелкими.
4. Второй раунд ревью нашёл 5 серьёзных замечаний, все исправлены.
5. Третий прогон добивает межмодульные правки, критику полноты, документацию и финальную проверку глазами компилятора.

Прогоны дважды прерывались из-за лимитов и возобновлялись с сохранением готовых результатов.

## Ограничения

- **Компилятора нет.** В контейнере нет Swift и Metal. Код проверен только чтением и скриптом tools/check.py. При первой сборке в Xcode 26 возможны мелкие ошибки компиляции.
- **Голоса системные.** Качество речи зависит от установленных голосов iOS. Улучшенные голоса скачиваются в настройках устройства.
- **Генерация шаблонная.** LLM не подключён, есть только протокол для него.
- **Иконки нет.** Набор иконки приложения содержит слоты без картинки.

## Как запустить

1. Открыть `LumiTales.xcodeproj` в Xcode 26.
2. Выбрать схему LumiTales и устройство или симулятор с iOS 26.
3. Для тестов пакета открыть папку `StoryCharacters` и запустить тесты.
